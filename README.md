# Day 4 – Authentication Methods

## Objective
Configure Microsoft Entra ID authentication methods and create a Temporary Access Pass (TAP).

## Environment
- Microsoft Entra ID
- Global Administrator
- Test User: Alex Brown

## Tasks Performed
- Enabled Temporary Access Pass policy.
- Created a Temporary Access Pass.
- Verified the pass appears under Authentication Methods.
- Confirmed expiration time.
- Reviewed available authentication methods.

## Result
The Temporary Access Pass was successfully created and assigned to the user.
