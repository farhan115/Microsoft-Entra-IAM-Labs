# Day 21 – Configure Microsoft Graph API Permissions

## Objective

Configured Microsoft Graph API permissions for an application in Microsoft Entra ID.

## Lab Environment

- Microsoft Entra ID
- IAM-Lab-App

## Tasks Performed

- Opened App Registration.
- Reviewed existing API permissions.
- Added Microsoft Graph delegated permission.
- Granted the User.Read permission.
- Verified the permission assignment.

## Skills Learned

- App Registration
- API Permissions
- Microsoft Graph
- Delegated Permissions
- OAuth 2.0 Authorization

## Result

Successfully configured Microsoft Graph delegated permission (User.Read) for the application.
