# Day 1 - Users and Groups in Microsoft Entra ID

## Objective
Learn how to create users, security groups, and manage group memberships in Microsoft Entra ID.

## Environment
- Platform: Microsoft Entra ID
- Tenant: Microsoft Entra Free
- Administrator Role: Global Administrator

## Tasks Completed
- Created three test users
- Created three security groups
- Assigned users to security groups
- Verified group membership

## Users

| User | Department |
|------|------------|
| John Smith | IT |
| Sarah Johnson | HR |
| Mike Davis | Finance |

## Security Groups

| Group | Purpose |
|------|---------|
| SG-IT-HelpDesk | IT Department |
| SG-HR-Team | Human Resources |
| SG-Finance-Team | Finance Department |

## Skills Practiced
- User Administration
- Group Administration
- Identity Management
- RBAC Fundamentals

## Lessons Learned
Security groups simplify access management by allowing permissions to be assigned to groups rather than individual users.
