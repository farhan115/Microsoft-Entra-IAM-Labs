## Key Concepts

### Password Protection

Microsoft Entra ID Password Protection helps prevent users from choosing weak or commonly used passwords by comparing them against Microsoft's global banned password list and optional custom banned passwords.

### Smart Lockout

Smart Lockout helps defend against password spray and brute-force attacks by temporarily locking accounts after repeated failed sign-in attempts while allowing legitimate users to regain access after the lockout period.
