# Day 22 – Assign an Owner to an App Registration

## Objective

Assign an owner to an application registration in Microsoft Entra ID.

---

## Lab Environment

- Microsoft Entra ID
- App Registration: IAM-Lab-App

---

## Tasks Performed

- Opened the IAM-Lab-App registration.
- Navigated to the Owners section.
- Added a user as an application owner.
- Verified the owner assignment.

---

## Why Application Owners Matter

Application owners are responsible for managing an application's configuration. They can update settings, manage certificates and secrets, configure API permissions, and maintain the application without requiring Global Administrator privileges.
