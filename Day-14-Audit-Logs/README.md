## Key Concepts

### Audit Logs

Audit Logs record administrative actions performed within Microsoft Entra ID, such as user creation, group management, application registration, and policy changes.

### Audit Event Information

Each audit record includes:

- Activity
- Initiated By
- Target Resources
- Status
- Date and Time
- Category

### Why Audit Logs Matter

Audit logs help administrators:

- Investigate security incidents
- Track configuration changes
- Meet compliance requirements
- Troubleshoot identity issues
