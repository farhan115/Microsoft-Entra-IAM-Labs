---

## Key Concepts

### Sign-in Logs

Sign-in Logs record authentication events for users attempting to access Microsoft Entra-protected resources.

### Information Available

Each sign-in event may include:

- User
- Application
- Sign-in status
- Date and time
- IP address
- Client application
- Location
- Device information (license dependent)

### Why Sign-in Logs Matter

Sign-in logs help administrators:

- Detect suspicious login attempts
- Troubleshoot authentication problems
- Monitor user activity
- Support security investigations
