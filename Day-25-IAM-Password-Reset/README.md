# Day 25 – IAM Ticket #003: Password Reset and Authentication Methods Review

## Objective

Simulate a real-world IAM support request by reviewing authentication methods, performing a password reset, and validating user activity in Microsoft Entra ID.

---

## Scenario

Employee **Emma Wilson** reported being unable to sign in after forgetting her password. The IAM team was tasked with resetting the password, reviewing authentication methods, and verifying recent account activity.

---

## Lab Environment

- Microsoft Entra ID
- Microsoft Entra Admin Center
- Microsoft Entra ID Free Developer Tenant

---

## Tasks Performed

### 1. Reviewed User Account

Verified the user's account information before making changes.

### 2. Reset Password

Attempted to reset the user's password and require a password change at the next sign-in.

### 3. Reviewed Authentication Methods

Verified the authentication methods configured for the account.

### 4. Reviewed Sign-in Logs

Checked recent sign-in activity for the user.

### 5. Reviewed Audit Logs

Reviewed administrative activities related to the account, including user creation, group changes, and password management events.

---

## Skills Demonstrated

- Password Management
- Authentication Methods
- User Account Administration
- Sign-in Monitoring
- Audit Log Review
- Microsoft Entra ID Administration
- Identity and Access Management (IAM)

---

## Business Outcome

Successfully completed a simulated IAM support request by reviewing authentication methods, resetting the user password (or documenting tenant limitations), and validating user activity through sign-in and audit logs.

---

## Key Learning Points

- Reset user passwords securely.
- Require password changes after temporary password issuance.
- Review configured authentication methods.
- Investigate sign-in activity.
- Use audit logs for troubleshooting and compliance.

---

## Technologies Used

- Microsoft Entra ID
- Microsoft Entra Admin Center
- Microsoft Entra ID Free Developer Tenant

---

## Conclusion

This lab demonstrated common IAM help desk responsibilities, including password management, authentication review, and auditing. These tasks are routinely performed by IAM analysts to maintain secure user access and support identity operations.
