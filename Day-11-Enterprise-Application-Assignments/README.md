---

## Key Concepts

### Enterprise Application

Enterprise Applications provide authentication and authorization for SaaS and internal applications using Microsoft Entra ID.

### User Assignment

Administrators can assign individual users or groups to applications to control access.

### Default Access

When no custom application roles exist, assigned users receive the Default Access role.
