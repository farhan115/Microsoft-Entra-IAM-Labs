## Key Concepts

### Named Locations

Named Locations identify trusted countries or IP address ranges. They are commonly used in Conditional Access policies to allow or block access based on where a user signs in from.

### Conditional Access

Conditional Access evaluates user, device, application, and location signals before allowing access to resources.
