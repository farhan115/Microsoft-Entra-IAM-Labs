## Key Concepts

### App Registration

An App Registration defines an application's identity, authentication settings, API permissions, and redirect URIs.

### Service Principal

A Service Principal is the instance of an application within a Microsoft Entra tenant. It is used for authentication, authorization, and assigning access to resources.

### Enterprise Application

Enterprise Applications are the tenant-specific view of Service Principals. Administrators use them to manage user assignments, sign-in settings, permissions, and access.
