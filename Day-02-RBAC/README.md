# Day 2 – Role-Based Access Control (RBAC)

## Objective

Learn how Microsoft Entra administrative roles provide secure access based on job responsibilities.

## Tasks Completed

- Reviewed built-in administrative roles
- Assigned the Helpdesk Administrator role to a test user
- Compared administrative roles
- Applied the principle of least privilege

## Role Comparison

| Role | Purpose |
|------|---------|
| Global Administrator | Full administrative control |
| Helpdesk Administrator | Password reset and basic user support |
| User Administrator | User and group management |
| Authentication Administrator | Manage authentication methods |
| Security Reader | View security information |

## Key Learnings

- RBAC limits permissions based on job responsibilities.
- Users should receive only the permissions needed to perform their work.
- Global Administrator should be assigned to as few accounts as possible.

## Skills Practiced

- Role assignment
- Administrative role management
- Least privilege
- RBAC fundamentals
