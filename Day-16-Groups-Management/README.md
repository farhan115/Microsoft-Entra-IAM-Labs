---

## Tasks Performed

- Opened All Groups.
- Created a Security Group.
- Added a user to the group.
- Reviewed group properties.

---

## Key Concepts

### Security Groups

Security groups simplify permission management by allowing administrators to assign permissions to a group instead of individual users.

### Assigned Membership

With assigned membership, administrators manually add or remove users from the group.

### Benefits of Groups

- Simplify access management
- Reduce administrative effort
- Support role-based access control (RBAC)
- Improve scalability in enterprise environments
